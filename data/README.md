# 命令速查数据

`commands.html` 的命令内容全部放在这个目录里，改内容不用碰 HTML。

## 文件

| 文件 | 作用 |
|---|---|
| `categories.json` | 分类清单，数组，**顺序即顶部 Tab 的顺序** |
| `<id>.json` | 该分类的内容，文件名必须和清单里的 `id` 对上 |

## 格式

只有一种内容类型：**单行条目**。

`categories.json`：

```json
[
	{ "id": "bash", "name": "Bash", "icon": "⌨️" },
	{ "id": "git",  "name": "Git",  "icon": "🌿" }
]
```

- `id` —— URL hash，也是 deep link：`commands.html#git`。**别改已有分类的 id**，旧书签会失效
- `name` —— Tab 上显示的名字
- `icon` —— Tab 上的 emoji

`<id>.json`：

```json
{
	"blocks": [
		{
			"g": "文件与目录",
			"items": [
				{ "cmd": "ls -alh", "d": "列出全部文件，含隐藏文件" },
				{ "cmd": "cd /",    "d": "进入根目录" },
				{ "cmd": "⌘ + C",   "d": "复制" }
			]
		}
	]
}
```

**排版规则**：只含基本值、且压成一行不超过 **110 个字符**的对象写成一行，其余才展开。
上面这些 `{ "cmd": …, "d": … }` 都是一行的；碰到很长的说明会自己展开成多行，
免得一行拖出屏幕。手改时照这个风格来，diff 才干净。

分组就是 `{ g, items }`，`items` 是一串单行条目：

| 字段 | 说明 |
|---|---|
| `cmd` | 点一下就复制的文本，渲染成可点击复制的代码条 |
| `d` | 右侧的说明文字，可省略 |

只有这两个字段。命令和快捷键不再区分——`"ls -alh"` 和 `"⌘ + C"` 走同一条路径，都只是「一段可复制的文本」。

### 曾经有过、现在去掉的写法

早期这三种都支持过，现在全部删掉了：

- **多行备注块**（`{"notes": [{"lines": [...]}]}`）—— 用来看 `ps aux` 各列含义那种对齐的表格。
  现在直接写成一行一条：`{"cmd": "USER", "d": "进程所有者的用户名"}`，渲染出来是一样的表格，反而更好点。
- **条目内小标题**（`h` 字段）—— 全站没有一条在用。
- **快捷键类型**（`k` 字段，渲染成居中的按键条）—— macOS 那 115 条已全部改成 `cmd`。
  如果以后觉得快捷键需要另一样式，现在得手工加一个字段了。

如果以后又需要多行内容，还是拆成多条写，别把多行塞进一个字符串。

## 怎么加

**加一条** —— 在对应文件的 `items` 里加一项：

```json
{ "cmd": "要复制的命令", "d": "右侧说明" }
```

**加一个分类** —— 两步，都在 `categories.json` 里手改：

1. 在 `categories.json` 里加一项
2. 新建 `data/<id>.json`，内容是 `{ "blocks": [ ... ] }`

只建了文件没在清单里加，它不会出现；只在清单里加了却没建文件，那个 Tab 会是空的。

## 更省事的办法

上面的格式完全可以手改，但如果你不想一直对着 JSON，仓库里有可视化编辑页：

**[`commands-edit.html`](../commands-edit.html)** —— 表单式增删改、右侧实时预览，改完直接导出各分类的 JSON 文件，把文件拖进 `data/` 提交即可。

它只管分组和条目；分类清单仍然手改 `categories.json`，编辑器**不会生成**它 —— 两边都改的话，你手改的分类名会被页面里的旧副本覆盖回去。

## 几个坑

- **别用 `_data/` 目录。** 那是 Jekyll 的内置数据目录，会被读进 `site.data`，不会作为静态文件输出 —— 本地起服务器能打开，线上是 404。就用 `data/`。
- **JSON 里不能写注释。** 想留说明就放到本文件，或者写进 `d` 字段。
- **命令里的引号要转义**：`"git commit -m \"msg\""`。
- **删掉最后一项后别忘了把上一项末尾的逗号也删掉**，JSON 末尾多余的逗号会直接解析失败。
- 本地看效果要用静态服务器（`python3 -m http.server`），直接双击 `file://` 打开会因为跨域而取不到数据。

## 校验

改完可以在本地跑一下，顺带确认没写错：

```sh
python3 -c "import json,glob; [json.load(open(f)) for f in ['data/categories.json']+glob.glob('data/*.json')]; print('JSON 全部合法')"
```
